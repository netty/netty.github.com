Netty 4.2.21.Final released

by chrisvest
on 16-Nov-2026

We are happy to announce the release of Netty 4.2.21.Final. This is a bug-fix release.

Note that Netty 4.1 will be End-of-Life on July 1st, 2027.

This release fixes a mistake in our build that affected Netty 4.2.20 and 4.1.140, where we accidentally increased the glibc version to 2.33 for x86_64 and aarch64. In this release the glibc version requirements return to their previous versions.

Other significant changes are:

  • Stop decoding in Bzip2Decoder after an error #18259
  • Only mirror 127.0.0.1 to the IPv6 loopback in DnsQueryContextManager #18263
  • NIO: Correctly catch all exceptions when NioDatagramChannel.block(...) fails #18234
  • Close channels that are still registered when an IoEventLoop exits on shutdown #18035
  • IoUring: Fall back to buffered writes for non-FileChannelImpl channels #18229
  • Upgrade lz4-java to 1.13.0 #18264
  • Include TrustManager / KeyManager instances in TLS session id context computations #18256
  • Honour qvalues when HttpContentCompressor selects the content encoding #17726
  • Use HTTP dates in ReadOnlyHttp2Headers.containsTimeMillis #18271
  • Avoid String.format in MacAddressUtil.formatAddress #18172
  • Initialize the hexadecimal tables of StringUtil lazily and cheaply #18174
  • Use the configured directory when creating disk attributes #18297
  • SslHandler: Stop wrapping when the transport can not keep up #18253
  • Encode the char after an unpaired high surrogate in writeUtf8(...) #18252
  • Close a QUIC stream reset #18313
  • Use the real parameter names in argument-check messages #18309
  • Quic: don't permanently consume stream ids when createStream(...) fails #18311
  • HTTP3: Reject invalid and connection-specific header fields #18298
  • Security improvement - allow MqttDecoder's maxBytesInMessage to be changed #18125
  • Discard input after a failed Socks5PrivateAuthRequestDecoder decode #17945
  • Call handshakeFailure for failed TLS completion events #18323
  • Release the handshake response when a WebSocket extension is rejected #18322
  • Notify LeakListener for every detected leak #18324
  • Avoid redundant flush scheduling after draining NIO writes #18296
  • Get plain 'mvn compile' and 'test-compile' working #18300
  • IoUring: Merge small buffers between large ones for SENDMSG_ZC #18250
  • Check the range in ByteBuf.toString(index, length, charset) #18156
  • Fail the h2c upgrade stream for all header conversion errors #18258
  • KQueue/Epoll: Fall back to buffered writes for non-FileChannelImpl channels #18349
  • Handle zero-length and invalid bulk reads in ByteBufInputStream #18272
  • Avoid classloader leak via the shared TransferEncodingNotAllowedException #18342
  • Avoid classloader leak via the QPACK stream inactive exceptions #18343
  • Avoid classloader leak via ImmediateEventExecutor terminationFuture failure #18338
  • Fix float matching in read-only HTTP/2 headers #18294
  • Fixed: Call handshakeFailure for TLS timeouts and early closes #18363
  • Keep adaptive buffer sizes within configured bounds #18358
  • Skip the renegotiation check for servers on BoringSSL and AWS-LC #18337
  • Canonicalize NaN values written #18295
  • Link synchronization.lib when building the QUIC codec on Windows #18371
  • Reject all control characters and DEL in HTTP response reason phrases #18331
  • Key per-channel traffic shaping state #18333
  • Fix ZstdDecoder and ZstdDecompressor with a non-positive defaultMaxForwardBytes #18289
  • Fix accidental glibc version bump #18365
  • Update BlockHound allowances for handleLoopException #18380
  • Evict DNS cache entries when expiration tasks are cancelled #18389
  • Fix BrotliDecoder with a non-positive defaultMaxForwardBytes #18378
  • Convert known signature algorithm names without the regular expression #18379
  • Resume SslHandler when the delegated task was consumed elsewhere #18406
  • Fix limit of bytes for gathering writes being ignored after the first buffer #18405
  • Use the correct address length when sending batched datagrams to a domain socket #18410
  • Reject negative session timeout and cache size in the QUIC SSLSessionContext #18414
  • Reject SPDY frames that do not fit the 24-bit length field #18412
  • Don't stop reading domain datagrams after an empty datagram #18408
  • Share enabled protocols in openssl engine #18388
  • Query SSL_pending lazily in ReferenceCountedOpenSslEngine.unwrap #18376
  • Release messages written to a closed EmbeddedChannel #18332
  • IoUring: Fail when enabling the ring fails #18216
  • Pin rustc to 1.100.0 in docker images and workflows #18422
  • HAProxyMessageEncoder: Reject v2 headers longer than 65535 bytes #18428

For more details please see the complete release notes.
