Netty 4.1.141.Final released

by chrisvest
on 16-Nov-2026

We are happy to announce the release of Netty 4.1.141.Final. This is a bug-fix release.

Note that Netty 4.1 will be End-of-Life on July 1st, 2027.

This release fixes a mistake in our build that affected Netty 4.2.20 and 4.1.140, where we accidentally increased the glibc version to 2.33 for x86_64 and aarch64. In this release the glibc version requirements return to their previous versions.

Other significant changes are:

  • Reject too long UDS paths in sendTo instead of truncating them #18245
  • Don't invert IP_MULTICAST_LOOP_DISABLED in NioDatagramChannelConfig #18243
  • Update Brotli4j version to 1.24.0 #18247
  • Fix FastLz.readU16 when the reader index is not 0 #18246
  • Grow KQueueEventArray correctly in realloc #18248
  • Complete the TCP fast open connect before notifying the initial write #18244
  • Stop decoding in Bzip2Decoder after an error #18261
  • NIO: Correctly catch all exceptions when NioDatagramChannel.block(...) fails #18267
  • Only mirror 127.0.0.1 to the IPv6 loopback in DnsQueryContextManager #18265
  • Upgrade lz4-java to 1.13.0 #18280
  • Honour qvalues when HttpContentCompressor selects the content encoding #18288
  • Use HTTP dates in ReadOnlyHttp2Headers.containsTimeMillis #18287
  • Initialize the hexadecimal tables of StringUtil lazily and cheaply #18292
  • Avoid String.format in MacAddressUtil.formatAddress #18291
  • Use the configured directory when creating disk attributes #18302
  • KQueue/Epoll: Fall back to buffered writes for non-FileChannelImpl channels #18278
  • Encode the char after an unpaired high surrogate in writeUtf8(...) #18307
  • Release the handshake response when a WebSocket extension is rejected #18329
  • Notify LeakListener for every detected leak #18334
  • Call handshakeFailure for failed TLS completion events #18327
  • Check the range in ByteBuf.toString(index, length, charset) #18340
  • Fail the h2c upgrade stream for all header conversion errors #18346
  • Handle zero-length and invalid bulk reads in ByteBufInputStream #18351
  • Avoid classloader leak via the shared TransferEncodingNotAllowedException #18356
  • Avoid classloader leak via ImmediateEventExecutor terminationFuture failure #18359
  • Fix float matching in read-only HTTP/2 headers #18362
  • Call handshakeFailure for TLS timeouts and early closes #18367
  • Keep adaptive buffer sizes within configured bounds #18375
  • Canonicalize NaN values written #18373
  • Reject all control characters and DEL in HTTP response reason phrases #18381
  • Key per-channel traffic shaping state #18386
  • Fix ZstdDecoder with a non-positive defaultMaxForwardBytes #18401
  • Fix limit of bytes for gathering writes being ignored after the first buffer #18396
  • Evict DNS cache entries when expiration tasks are cancelled #18393
  • Resume SslHandler when the delegated task was consumed elsewhere #18372
  • Fix BrotliDecoder with a non-positive defaultMaxForwardBytes #18398
  • Don't stop reading domain datagrams after an empty datagram #18395
  • Use the correct address length when sending batched datagrams to a domain socket #18394
  • Fix accidental glibc version bump #18390
  • Reject SPDY frames that do not fit the 24-bit length field #18417
  • HAProxyMessageEncoder: Reject v2 headers longer than 65535 bytes #18430

For more details please see the complete release notes.
